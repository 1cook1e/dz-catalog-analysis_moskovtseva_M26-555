
# Анализ каталога фильмов

Мини-проект на Python для анализа каталога фильмов.

## Возможности программы

- Расчёт среднего рейтинга и возраста фильмов.
- Перевод продолжительности в часы и минуты.
- Определение категории рейтинга и десятилетия.
- Сортировка фильмов по рейтингу.
- Подсчёт фильмов по жанрам.
- Поиск фильмов с участием определённого актёра.
- Работа с множествами и генераторами.
- Формирование итогового отчёта.

## Запуск

Проект использует Python 3.12 и uv.

```powershell
uv run --python 3.12 catalog_analysis.py
```

## Проверка кода

```powershell
uv run --with ruff ruff check catalog_analysis.py
```
